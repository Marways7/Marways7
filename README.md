### 你好，我是 Marways。

**用 AI 写代码，也用代码探索 AI。** 我喜欢把具体的问题拆开，把零散的灵感接上，做成能够被尝试、被改进的东西。

我的好奇心常常沿着三条路线出发：**从信号里发现规律，从阅读中打开理解，让 AI 走向实际的工具与交互。** 这里记录我的开源实验，也为下一个「能不能」留着位置。

## 从一个问题，到一个作品

**[ECG Identification](https://github.com/Marways7/ECG_IdentificationX)** 把信号处理与轻量 CNN 结合，探索 ECG 生物特征身份识别。关注的是心电信号中的身份特征。

### 一句话、一页书，能不能多一个入口？

<p>
  <a href="https://github.com/Marways7/AiliaoX"><picture><source media="(prefers-reduced-motion: reduce)" srcset="./assets/play/ailiao-still.svg" /><img src="./assets/play/ailiao.svg" width="49%" alt="AiliaoX：AI 对话与 MCP 工具，探索医院信息交互。" /></picture></a>
  <a href="https://github.com/Marways7/DeepReadX"><picture><source media="(prefers-reduced-motion: reduce)" srcset="./assets/play/read-still.svg" /><img src="./assets/play/read.svg" width="49%" alt="DeepReadX：Android PDF、OCR 与可自定义风格的 AI 解释。" /></picture></a>
</p>

**[AiliaoX](https://github.com/Marways7/AiliaoX)** — 通过自然语言表达意图，用 MCP 工具连接医院信息与操作，探索更直接的交互方式。

**[DeepReadX](https://github.com/Marways7/DeepReadX)** — 一个 Android AI 辅助阅读项目。把 PDF、OCR 和可自定义风格的解释放在一起，让一页文字多一种被理解的方式。

### 从「说出来」，再往「做出来」走一步。

<p>
  <a href="https://github.com/Marways7/cua_desktop_operator_skill"><picture><source media="(prefers-reduced-motion: reduce)" srcset="./assets/play/desktop-still.svg" /><img src="./assets/play/desktop.svg" width="49%" alt="Desktop Operator：面向 AI 的桌面操作工具，提供 MCP 与 CLI 入口。" /></picture></a>
  <a href="https://github.com/Marways7/signal-sprint"><picture><source media="(prefers-reduced-motion: reduce)" srcset="./assets/play/sprint-still.svg" /><img src="./assets/play/sprint.svg" width="49%" alt="Signal Sprint：围绕直播准备流程，结合实测与本地回放改进启动节奏。" /></picture></a>

**[Desktop Operator](https://github.com/Marways7/cua_desktop_operator_skill)** — 面向 AI 的桌面操作工具，探索意图、界面与行动的连接。提供 [MCP 版本](https://github.com/Marways7/cua_desktop_operator_skill) 和 [CLI 版本](https://github.com/Marways7/cua_desktop_operator_cli_skill)。

**[Signal Sprint](https://github.com/Marways7/signal-sprint)** — 从直播准备流程里的小摩擦出发，把实测和本地回放结合，改进扫码准备与启动节奏。
