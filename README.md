### 你好，我是 Marways。

我用 AI 写代码，也用代码探索 AI。喜欢把具体的问题拆开，把零散的灵感接上，做出能够被尝试、被改进的东西。

从心电信号中的身份特征，到一页 PDF 的理解；从 AI 对话，到桌面上的行动。我在探索 **技术怎样成为真正用得上的工具**。

这里记录我的开源实验，也留着下一个“能不能”的位置。
