### 一个「能不能」，就是一个开始。

你好，我是 **Marways**。我喜欢把一个奇怪的念头，做成你能亲手试试的东西。

从心电信号里的身份特征，到能讲清一页 PDF 的 AI；从自然语言驱动的信息系统，到让 AI 真正操作桌面的工具——我在探索 **AI 与现实之间，具体能发生什么**。

**想法可以跳跃，作品要落地。** 这里记录我的实验、学习和开源作品。
