# Marways — 个人介绍页设计与交互说明

## 命题

Marways 的项目横跨心电身份识别、AI 阅读、医院信息交互、桌面工具和知识分享。共同点是：让不易理解的信号变成可理解、可使用的东西。个人介绍页以此为线索，用连续演化的视觉连接作品。页面首先服务于认识 Marways、理解项目与访问代码；艺术品般的完成度是质量目标，不是把页面改成艺术展览。

## 对上一版的评审

1. 铬金属数字 7 有辨识度，但与真实作品缺少语义联系；形状按钮没有构成旅程。
2. 页面里只有一个主要场景，向下阅读又回到常规作品面板；用户的探索没有改变空间。
3. 明亮材质、粒子、巨字争夺注意力。作品文字和可点击入口相对弱。
4. 手机第一屏的雕塑占用过多高度，交互提示与入口出现太晚。

## 三个候选方向

| 方向 | 优势 | 取舍 |
| --- | --- | --- |
| 光学实验室 | 材质与光线精致，容易形成一致语言 | 仍容易成为抽象装饰，与上一版接近 |
| 数字植物志 | 形态生长、不同形态、观看者影响形态，与项目主题可直接对应 | 需要精确编排形态、转场和文字 |
| 巨型文字剧场 | 语言辨识度强、加载轻 | 场景空间感相对有限 |

采用连续演化的参数化形态，结合大尺寸个人署名。各形态来自项目语义，作为作品的视觉表达；导航和正文使用直接的个人介绍与项目语言，不使用博物馆式包装。

## 视觉系统

- 瓷白 `#ECEEE9`：入口的展览空间。
- 墨绿 `#183D35`：文字与有机形态的阴影。
- 花粉黄 `#D8E39E`：阅读和知识传播的轻盈感。
- 胭脂 `#A4364E`：心电的生命感。
- 深莓 `#261F29`：心电章节的暗场。
- 雾蓝 `#CDDDE6`：知识连接的开阔空间。
- Sora：署名与展品标题，清晰的大尺寸低字重。
- 系统中文无衬线：介绍、项目事实、导航。保持正文易读。
- 不新增外部字体请求、第三方统计、假实时计数或装饰徽章。

桌面：顶部宽署名，画面中心偏右放雕塑，左下放内容；右侧垂直路线选择章节；底部展示当前章节与观赏控制。手机：雕塑居上、文字在下，控制留在可触及位置。

```

          living possibilities
                [视觉形态]

进入项目                                  图

```

| 章节 | 形态 | 内容 |

| 首屏 | 放射状的褶皱花冠 | 让好奇，有生命 |
| 心跳 | 起伏环绕的信号带 | ECG 生物特征身份识别研究 |

## 运动设计

使用原生滚动，位置决定转场进度，可随时反向。每个章节预留稳定阅读区；离开章节时，表面向外展开、旋转、再收束成下一件形态，空间颜色与文字同时交接。指针轻微影响光线与视角；拖动雕塑改变角度；“绽放”让表面短暂展开后回归。观看模式隐藏阅读层但保留退出与章节导航。

自动运动只是缓慢呼吸，主要运动由观看者触发。暂停后仍可切换章节和查看项目，但不继续自动旋转。减少动态设置直接切换场景并取消自动呼吸。无图形加速时使用静态插图，所有项目仍可阅读。

## 工程与验证边界

同一画布、相同拓扑的预计算形态，避免滚动时创建大量对象。限制像素比，长帧时降分辨率；页面隐藏时停止绘制。按实际浏览器验证效果，不宣称所有硬件达到固定帧率。

检查桌面和手机截图、所有章节、正反方向转场、暂停、观看模式、目录对话框与键盘、项目链接、减少动态和无 WebGL 后备。README 使用同主题的独立动画 SVG，完整交互由 GitHub Pages 承载。
